# Personas

Only personas justified by current scope are detailed; others are named as
future extension points.

## Website Visitor

Prospective client or partner researching ATS. Wants to quickly understand
what ATS does and how to get in touch. No account required.

## Content Manager (future)

Will need to publish/update site content (services, blog) without a
developer. Not yet built — informs the future admin app but does not block
the current phase.

## Developer

Human or AI agent working in this repository. See root AGENTS.md.
