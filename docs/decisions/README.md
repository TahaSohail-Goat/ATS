# Architecture Decision Records (ADRs)

ADRs capture significant, hard-to-reverse architectural decisions and the
reasoning behind them. See root `AGENTS.md` §9 for the exact list of
decisions that require an ADR before implementation.

## Process

1. Copy `ADR-0001-template.md` to `ADR-XXXX-short-title.md` (next sequential
   number).
2. Fill it in _before_ implementing the decision.
3. Open a PR with the ADR for review/discussion.
4. Once merged, the decision is considered accepted; implementation PRs
   reference it.
