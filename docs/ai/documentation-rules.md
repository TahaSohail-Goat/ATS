# Documentation Rules (AI-agent specific notes)

- Docs are the source of truth (root `AGENTS.md` principle #1). A code
  change that makes a doc inaccurate is not finished until the doc is
  updated in the same PR.
- Use `**TBD:**` for genuinely undecided items instead of inventing a
  plausible-sounding answer.
- Keep the tone and structure consistent with the existing doc set — don't
  introduce a new documentation format for one page.
